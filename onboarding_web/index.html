Connect a bot token

  1. Open @BotFather → /newbot (or /token for an existing bot).
  2. Paste the token below. It is sent only to ClickMint over HTTPS, encrypted at rest, and never posted into any chat.
  3. Then add your bot as an administrator of your channel/group and run /register @name in the bot.

Never send your token as a chat message. If you already did, revoke it in @BotFather (/revoke) and paste the new one here.
